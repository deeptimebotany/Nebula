# Polices auto-hébergées

Les deux polices ci-dessous sont servies directement par le site (aucun appel
à Google Fonts au chargement — ni au build, ni côté visiteur), via
`next/font/local` dans `src/app/layout.tsx`.

- `inter-variable-latin.woff2` — Inter (police variable, sous-ensemble latin),
  © The Inter Project Authors, licence SIL Open Font License 1.1.
  https://github.com/rsms/inter
- `space-grotesk-variable-latin.woff2` — Space Grotesk (police variable,
  sous-ensemble latin), © Florian Karsten, licence SIL Open Font License 1.1.
  https://github.com/floriankarsten/space-grotesk

Fichiers extraits des paquets npm `@fontsource-variable/inter` et
`@fontsource-variable/space-grotesk` (version 5), qui redistribuent ces
polices sous la même licence.
